# 2026-hack · AstroFrontier

**Abandoned, but Not Forgotten** — an interactive storybook website for the NASA Space Apps Challenge by team AstroFrontier.
Shasha and her cat Miaw Miaw travel to Mars to meet the forgotten rovers **Spirit** and **Opportunity**.

## See it live
Turn on GitHub Pages (Settings → Pages → Branch: `main`, folder `/ (root)`), then open:
`https://astrofrontiernasa-arch.github.io/2026-hack/`

## What's inside
| File | What it is |
|---|---|
| `index.html` | The whole website, with the story add-on at the end |
| `scene1-bedroom.mp4`, `scene2-rocket.mp4`, `scene3-*.mp4` | Scene videos |
| `scene1-music.mp3`, `scene2-music.mp3`, `scene3-music.mp3` | Scene music |
| `shasha-*.webp`, `miaw-*.webp` | Character pictures (game button, floating characters, NASA data assistant) |
| `astrofrontier_logo_transparent.svg` | Team logo |
| `voice-lines.txt`, `voice/` | Optional: record real voices for every line |
| `story-addon-only.html` | The story add-on on its own (for pasting into another copy of the page) |
| `images/` | Team images |

Facts in the story come from NASA Science and NASA JPL pages (listed in the site's NASA data panel).
